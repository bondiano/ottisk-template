# ottisk-template

Шаблон курса «Агенты и LLM-разработка: типография «Оттиск»». В проверках курса код зовёт Болванку, детерминированную модель по сценарию. Здесь тот же код идёт в настоящую дешёвую модель со своим ключом, и каждая команда печатает, сколько стоил запуск.

## Что нужно

* Node.js 22.19 или новее и pnpm;
* ключ DeepSeek с platform.deepseek.com, если хочешь настоящую модель (без ключа всё работает на Болванке);
* pi, если проходишь урок 03: `npm install -g --ignore-scripts @earendil-works/pi-coding-agent`.

*Проверено на: pi 1.5.2, DeepSeek `deepseek-flash`, `openai` 7.38.0, 2026-11-11.*

```sh
pnpm install
cp .env.example .env   # MODEL=bolvanka или MODEL=deepseek и DEEPSEEK_API_KEY
```

Ключ живёт только в `.env`, его нет в репозитории (`.gitignore`). Команды проверяют `.env` на старте и говорят, какой переменной не хватает.

## Команды

| Команда | Урок | Что делает |
|---|---|---|
| `pnpm hello` | 03, 04 | приёмщик «Оттиска» на одном инструменте `price`: вопрос, вызов, ответ, токены и цена запуска |
| `pnpm hello "Сколько стоят 200 буклетов?"` | 04 | свой вопрос; на Болванке сценарий знает только приветствие и цену 500 визиток |
| `pnpm litera:train [шагов]` | 28, 30 | полное обучение Литеры, потеря на обучении и валидации, образцы; веса в `litera/weights.ts` |
| `pnpm litera:sample "Продам "` | 30 | три визитки по началу строки, самая уверенная первой |

## Урок 03: pi на DeepSeek

```sh
export DEEPSEEK_API_KEY=...        # или /login внутри pi
pi --provider deepseek --model deepseek-flash
```

Первая задача в этом каталоге: попроси pi прочитать `price.csv` и ответить, сколько стоят 500 визиток и какой у них минимальный тираж. Потом сверь ответ с файлом сам.

## Что внутри

* `src/bolvanka.ts`: Болванка, та же, что в проверках курса;
* `src/reception.ts`: приёмщик, который принимает клиент модели параметром;
* `src/scenario.ts`: сценарий Болванки для `pnpm hello`;
* `src/client.ts`: клиент по `MODEL` и цены DeepSeek на дату;
* `litera/`: эталон Литеры этапа 10; свои файлы этапа можно положить сюда же.
