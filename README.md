# ottisk-template

Шаблон курса «Агенты и LLM-разработка: типография «Оттиск»». В проверках курса код зовёт Болванку, детерминированную модель по сценарию. Здесь тот же код идёт в настоящую дешёвую модель со своим ключом, и каждая команда печатает, сколько стоил запуск.

## Что нужно

* Node.js 22.19 или новее и pnpm;
* ключ DeepSeek с platform.deepseek.com, если хочешь настоящую модель (без ключа всё работает на Болванке);
* pi, если проходишь урок 03: `npm install -g --ignore-scripts @earendil-works/pi-coding-agent`.

*Проверено на: pi 1.5.2, DeepSeek `deepseek-flash`, `openai` 7.38.0, 2026-11-11.*

```sh
pnpm install
cp .env.example .env   # MODEL=bolvanka или MODEL=deepseek и DEEPSEEK_API_KEY
```

Ключ живёт только в `.env`, его нет в репозитории (`.gitignore`). Команды проверяют `.env` на старте и говорят, какой переменной не хватает.

## Команды

| Команда | Урок | Что делает |
|---|---|---|
| `pnpm hello` | 03, 04 | приёмщик «Оттиска» на одном инструменте `price`: вопрос, вызов, ответ, токены и цена запуска |
| `pnpm hello "Сколько стоят 200 буклетов?"` | 04 | свой вопрос; на Болванке сценарий знает только приветствие и цену 500 визиток |
| `pnpm priemka [L01 L13 …]` | 117-126 | «Приёмка» урока 126 на письмах клиентов: заказы, причины для человека, токены и цена прогона; `MODEL=bolvanka\|deepseek\|openrouter\|yandex\|gigachat` |
| `pnpm litera:train [шагов]` | 28, 30 | полное обучение Литеры, потеря на обучении и валидации, образцы; веса в `litera/weights.ts` |
| `pnpm litera:sample "Продам "` | 30 | три визитки по началу строки, самая уверенная первой |
| `pnpm check` | 89 | typecheck + oxlint + Effect diagnostics + vitest; правка не готова, пока код возврата не 0 |

Оболочка (`hello`, `config`, `priemka/run`) на Effect 4. Копии Болванки, Литеры и ядра «Приёмки» остаются обычным TypeScript, как в проверках курса.

## Урок 03: pi на DeepSeek

```sh
export DEEPSEEK_API_KEY=...        # или /login внутри pi
pi --provider deepseek --model deepseek-flash
```

Первая задача в этом каталоге: попроси pi прочитать `price.csv` и ответить, сколько стоят 500 визиток и какой у них минимальный тираж. Потом сверь ответ с файлом сам.

## Уроки 117-126: «Приёмка»

`pnpm priemka` гоняет «Приёмку» этапа 10 (урок 126) по письмам клиентов из `priemka/fixtures/letters.ts`: заказ по схеме, повторы на сбоях провайдера, лимит запросов, квота на клиента, проверка макетов кодом и моделью, смета по прайсу. Без аргументов идёт утренняя пачка из шести писем, с аргументами только названные: `pnpm priemka L01 L13`.

```sh
pnpm priemka                      # MODEL=bolvanka: без сети и ключа
MODEL=deepseek pnpm priemka       # DEEPSEEK_API_KEY в .env
MODEL=openrouter pnpm priemka     # OPENROUTER_API_KEY и OPENROUTER_MODEL
MODEL=yandex pnpm priemka         # YANDEX_API_KEY и YANDEX_FOLDER_ID
MODEL=gigachat pnpm priemka       # GIGACHAT_AUTH_KEY и сертификат Минцифры, см. ниже
```

До первого запроса команда проверяет конфиг и называет переменную, которой не хватает: `Конфиг: нет ключа: задай DEEPSEEK_API_KEY`. Потом печатает строку на письмо (статус, заказ, число запросов к модели и причины, по которым письмо уходит человеку), токены прогона и его цену. Цена считается по `usage` ответов и тарифу из `priemka/fixtures/tariffs.ts` с пиком и без; рубли по учебному курсу 90 ₽ за доллар, а не по биржевому. Для Болванки цена $0 и рядом то, сколько тот же прогон стоил бы на `deepseek-flash`. Тарифов OpenRouter, Яндекса и GigaChat в шаблоне нет: команда печатает токены, а умножить их на цены провайдера придётся по его странице.

Болванка знает только утреннюю пачку: на другие письма она ответит `400 ход не найден`, и письмо будет `failed`, как в уроке 04.

GigaChat ходит по сертификату НУЦ Минцифры. Без него запрос токена падает строкой `Конфиг: fetch failed: self-signed certificate in certificate chain`. Не выключай проверку сертификата, а дай его Node: `NODE_EXTRA_CA_CERTS=/путь/к/russian_trusted_root_ca.cer MODEL=gigachat pnpm priemka`. Заказ «Приёмка» просит генерацией по схеме (`response_format: json_schema`, урок 120). У DeepSeek, Яндекса и GigaChat через OpenAI-совместимый API курс этого не проверял: если провайдер ответит 400 на `response_format`, письмо будет `failed` с текстом ошибки, и это повод для адаптера из урока 118.

*Проверено на: DeepSeek `deepseek-flash`, цены api-docs.deepseek.com, `openai` 7.38.0, `zod` 4.6.7, 2026-11-11.*

## Что внутри

* `src/bolvanka.ts`: Болванка, та же, что в проверках курса;
* `src/reception.ts`: приёмщик, который принимает клиент модели параметром;
* `src/scenario.ts`: сценарий Болванки для `pnpm hello`;
* `src/client.ts`: клиент по `MODEL` и цены DeepSeek на дату;
* `litera/`: эталон Литеры этапа 10; свои файлы этапа можно положить сюда же;
* `priemka/`: эталон «Приёмки» этапа 10 (`api/`, Болванка v2, `contracts.ts`, фикстуры) и свои файлы шаблона: `run.ts` (команда) и `scenario.ts` (утро на Болванке).
