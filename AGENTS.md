# ottisk-template · правила для агента

## Команды

* `pnpm install`, затем `pnpm check` после любой правки кода. Изменение не готово, пока `pnpm check` не прошёл.
* `pnpm hello` проверяет приёмщика на Болванке без сети. `MODEL=deepseek pnpm hello` ходит в сеть и тратит деньги: запускай только по просьбе человека.
* `pnpm priemka` гоняет «Приёмку» на Болванке без сети; с `MODEL=deepseek|openrouter|yandex|gigachat` она ходит в сеть, тратит деньги и отправляет провайдеру письма клиентов: тоже только по просьбе человека.

## Как устроен код

* Оболочка (`src/hello.ts`, `src/config.ts`, `src/errors.ts`, `priemka/run.ts`) на Effect 4: `Effect.gen`, tagged-ошибки, `Schema` для MODEL.
* Код, который зовёт модель, принимает клиент `OpenAI` параметром и сам его не создаёт; клиент выбирает `src/client.ts`.
* Цены и версии моделей стоят с датой проверки. Не меняй цену без ссылки на страницу цен.

## Нельзя

* Читать, печатать и коммитить `.env`; ключи только там.
* Менять `src/bolvanka.ts`, файлы `litera/` кроме `weights.ts` и файлы `priemka/` кроме `run.ts` и `scenario.ts`: это копии из курса.
